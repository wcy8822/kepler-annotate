KEPLER ANNOTATE · 1.4.0

把网页反馈变成可处理的批注

截图、原话、项目与批次保存在本地。可导出 ZIP，也可选用本地 Skill 协作。

加载到 Chrome

  1. 下载并解压项目，或克隆仓库。
  2. 在 Chrome 地址栏打开 chrome://extensions，启用右上角「开发者模式」。
  3. 点击「加载已解压的扩展程序」，选择包含 manifest.json 的项目目录。
  4. 打开网页，点击扩展图标。建议在扩展菜单中将它固定。

开始一轮批注

在清单中新建项目与批次，用点选、框选、画笔或箭头标记，选择分类后保存。悬停卡片或下拉菜单可使用「3秒后圈选」，或保持鼠标位置按 Alt+Shift+S（Mac：Option+Shift+S）定格，再圈选；按 Esc 恢复交互。

完成后「归档并新建」开始下一轮。「清空工作区」也会保留存档；可以切回历史批次编辑明细。每个页面只显示该页面的标记。

让 AI 处理

打开 README 查看可选 Native Messaging 安装；「项目本地」绑定项目后，批注与截图自动同步。安装随项目提供的 Skill 后，让 AI 按批次读取增量、整理需求、在分支修改并回写验证结果。真实项目上的改动仍由你的指令决定。

浏览器内部页等受 Chrome 限制的页面无法注入。同步与发送均由本地原生程序完成，需 Python 3；直接发送到 Codex 还需要 Codex CLI。原生安装器目前以 macOS 为验证平台。

无需账号；没有自动上传服务。导出内容可能包含网页地址、可见文字和截图，请在分享前检查。
